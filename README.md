## Функции

- **До 5000 CPS** — максимальная скорость кликов в стандартном режиме
- **Удержание клика** — режим зажатия кнопки с настраиваемой длительностью
- **Кастомная клавиша** — привязка кликов к любой клавише клавиатуры (до 800 CPS)
- **Горячая клавиша** — управление вкл/выкл одной кнопкой (по умолчанию F4)
- **Два режима активации** — переключение (toggle) или удержание (hold)
- **Профили** — сохраняйте и загружайте наборы настроек
- **Стабильность** — отслеживание целевой и секундной скорости в реальном времени
- **Always on Top** — окно всегда поверх других окон
- **Тёмный интерфейс** — удобный дизайн в тёмных тонах

## Настройки

| Параметр | Описание |
|----------|----------|
| **Кнопка мыши** | Левая / Правая / Средняя / Кастомная клавиша |
| **Удержание клика** | Режим зажатия с настраиваемой длительностью (0.01–60 сек) |
| **Горячая клавиша** | Клавиша для быстрого включения/выключения |
| **Режим активации** | Переключение (F4 вкл/выкл) или Удержание (зажал = кликает) |

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `F4` | Включение / выключение кликера (по умолчанию) |
| `Любая буква/цифра` | Задаёт кастомную клавишу кликера |

## Сборка из исходников

Требования: **Visual Studio 2019+** с поддержкой C++17

```bash
cd cpp
build.bat
```

Или откройте `cpp/main.cpp` в Visual Studio и соберите в режиме Release.

## Как использовать

1. Запустите `UltimaxClicker.exe`
2. Введите нужное количество **CPS** в поле ввода
3. Нажмите `F4` или перетащите окно — кликер начнёт работу
4. Настройте параметры через кнопку ⚙ в заголовке окна

## Как создать профиль

1. Откройте настройки (⚙)
2. Перейдите на вкладку **Профили**
3. Введите имя профиля в поле ввода
4. Настройте все параметры (кнопка, CPS, горячая клавиша и т.д.)
5. Нажмите **+ Сохранить текущие настройки**
